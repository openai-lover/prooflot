# Prooflot 제출 직전 평가

확인: 2026-11-15 KST, 제출 마감 전. 표시 이름은 Prooflot이다. 과거 AgentProof/BotPassport 이름으로 남은 문서는 해당 시점의 기록이다.

## 판단

**전체 사용 흐름과 실제 NEAR 거래 근거를 갖춘 제출용 MVP다. 우승이 유력하다고 단정할 근거는 없다.** 강점은 제작자의 실제 Python 파일이 검사·판매·구매·저장·새 실행까지 이어지고, 구매한 버전과 보고서·사용권의 연결을 파일과 체인에서 다시 확인할 수 있다는 점이다. 손실·적은 체결·짧은 기간도 화면에 남는다.

핵심 약점은 실행과 시장 데이터의 진실성을 운영자에게 의존한다는 점, 공개 과거 시험 네 개가 미공개 검증 데이터가 아니라는 점, 독립 사용자들의 사용성과 실제 수요가 아직 검증되지 않았다는 점이다. 공개 호스팅도 제공하지 않는다. 심사위원에게 거래 가능한 상품의 경계와 재현 방법을 명확하게 보여주는 것이 지금 가장 효과적이다.

## 공식 조건

[공식 안내](https://nearhackathon.com/HACKATHON.md)를 다시 확인했다. 마감은 2026-11-14 23:59 UTC, 한국 시간 **11월 15일 08:59**다. 테스트넷과 로컬 시연이 허용되며, 로컬 제품은 공개 저장소·재현 가능한 안내·영상이 첨부된 X 게시물이 필요하다. 최종 심사는 사람이 결정한다. 자체 NEAR 계약으로 참가할 수 있고 유료 LLM 호출은 필수 요건이 아니다.

트랙 제안은 **Open Innovation + Agent Economy**다. 검사한 소프트웨어 버전을 거래하는 시장이라는 제안이 중심이며, 구매 결정은 현재 사람이 한다. 자율 에이전트 간 협상이나 독립 실행 인증을 구현했다고 주장하지 않는다.

## 경쟁 표본 재확인

[공식 디렉터리 API](https://nearhackathon.com/api/projects?page=1)는 재확인 시 `total: 1504`를 반환했다. 자격 검증을 마친 팀 수나 실행 완료 제품 수로 해석하지 않는다. 전체를 실행·평가한 것이 아니다.

- [Veto](https://github.com/Bronxydrone/Veto)의 공개 설명은 NEAR 계약에서 에이전트 지출 정책을 강제하는 데 초점을 둔다. Prooflot도 구매할 버전·약관과 최종 권리를 계약에서 검사하므로 NEAR의 역할을 구체적으로 시연할 수 있다.
- [LeashPay](https://github.com/hassaanraja282-lgtm/leashpay)의 공개 저장소는 에이전트 지출 제한을 NEAR 계약으로 구현한다고 설명한다. Prooflot은 정상 결제뿐 아니라 변조한 약관·중복 결제·무권한 다운로드 거부와 사용권 복구를 증거로 제시한다.

두 저장소를 직접 실행하거나 보안 감사하지 않았고, 타 프로젝트의 자체 테스트 수를 우열 점수로 사용하지 않는다. 기존 Solana·Monad 수상작 조사와 이 프로젝트에 반영한 비교·재시험 기능은 [winner-benchmark.ko.md](winner-benchmark.ko.md)에 있다.

## 이번에 닫은 결함

1. 공개 소스의 로컬 모드에서도 제작자가 검사 후 상품을 게시할 수 있게 했다. 게시 직후 상품 화면으로 이동한다.
2. 앱 내 브라우저의 파일 선택창이 멈추는 문제를 피해 기본 동작을 일반 다운로드로 바꿨다. 위치 선택·저장 후 바이트 대조는 선택 기능으로 유지한다.
3. 실제 `.py` 업로드부터 구매·Windows Downloads 저장·오프라인 검증·73회 새 Python 판단까지 앱 내 브라우저에서 확인했다. [파일 증거](prooflot-browser-evidence.json).
4. 서비스 화면을 영어로 통일하고 Prooflot 이름·P 로고·소개에서 제품으로 이어지는 전환을 적용했다.
5. 전체 84개 테스트, 14개 실제 별도 계정 흐름, 개인 Meteor 구매 증거와 공개 RPC 검증 명령을 공개했다. 실제 거래 UI와 SDK 검증의 범위를 구분했다.

[공개 소스](https://github.com/openai-lover/prooflot)와 [공개 시연 영상](https://youtu.be/OEni-eWBdwk)이 있다. 영상은 로컬 결제 시연과 실제 테스트넷 기록 확인을 구분한다. 최종 접수 완료 여부는 별도 접수 응답을 기준으로 판단한다.
