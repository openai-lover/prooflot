# 수상작 조사와 제품 반영

확인일: 2026-11-12. 공식 수상 발표와 출품자가 연결한 제품·문서를 읽었다. 경쟁 서비스에 자금을 보내거나 코드를 실행·감사하지 않았다. 아래 개선 방향은 수상작을 보고 내린 제품 판단이며, NEAR 심사위원의 평가나 수상 확률이 아니다.

## 어떤 수상작을 확인했나

Solana 계열의 가을 Crypto World's Fair는 현재 공식 사이트에서 심사 중이다. 발표된 수상작을 확인할 수 있는 Frontier를 기준으로 삼았다. [현재 대회 상태](https://colosseum.com/hackathon)

## 이번에 실제로 구현한 것

- **같은 조건 비교:** 시장 데이터 해시·엔진·수수료·슬리피지·시작 자본·평가 구간을 고정한다. 2–3개 봇을 새로 실행하며, 실패·중단이 있으면 동일 조건 완료 표시를 주지 않는다. 유료 프롬프트 봇은 비교에서 제외한다.
- **성과의 근거:** 체결 수, 캔들 수, 짧은 관찰 구간과 합성 여부를 공개한다. 안전 등급이나 근거 없는 신뢰 점수를 부여하지 않는다.
- **비용과 구간:** 기존 매매 판단을 고정해 비용 1·2·3배 결과를 재계산한다. 초기·중간·후반 수익률을 표시한다. 새 조건의 봇 재실행이나 미공개 검증 데이터 시험으로 설명하지 않는다.
- **구매할 버전 확인:** 상세 페이지, 공개 보고서, 별도 분석 해시, 온체인 등록 기록, 최종 상태 재조회, 근거 파일 다운로드를 연결했다. 기존 불변 보고서를 추가 분석 때문에 수정하지 않는다.
- **짧은 첫 경험:** 첫 화면에서 두 예제를 한 번에 비교하고, 마켓에서 제작자 봇을 골라 같은 BTC 데이터로 시험한다. 캐릭터 없는 흰색·파란색 UI를 유지했다.

실행 결과와 한계는 [verification.md](verification.md), 실제 비교 기록은 [comparison-evidence.json](comparison-evidence.json)에 있다. 표본 기준 168개 캔들·10회 체결은 알림 규칙이지 통계적 신뢰도 기준이 아니다.

## 아직 경쟁력의 빈칸

현재는 검증 가능한 로컬·테스트넷 MVP다. 수상권 제품으로 평가받으려면 실제 제작자와 구매자의 문제·반복 사용·지불 의사를 보여줄 근거가 더 필요하다. 인터뷰·사용자·매출 숫자를 만들어 넣지 않았다. 개인 지갑 인증, 운영용 거래 복구, 장기간·다른 시장 구간 시험도 미완료다.

우선 확인할 질문은 “판매 전에 어떤 검사 결과를 보여주고 싶은가”, “구매 전에 같은 조건 재시험을 실제로 하는가”, “소스 제공 방식과 사용권 범위를 받아들일 수 있는가”다. 제작자 3명·구매 의향자 3명에게 직접 사용하게 한 뒤, 등록→완료→비교→구매 조건 확인의 이탈 구간과 이유를 기록하는 실험을 제안한다. 아직 수행한 사용자 조사로 표현하지 않는다.

NEAR 제출의 핵심은 작동하는 제품과 재현 가능한 설명이다. 현행 공식 문서상 테스트넷 프로젝트와 자체 NEAR 계약이 가능하고, 로컬 전용 데모에는 공개 저장소·재현 README·X 영상이 필요하다. 마감은 **11월 15일 오전 8:59 한국시간**이다. [NEAR 공식 제출 기준](https://nearhackathon.com/HACKATHON.md)
